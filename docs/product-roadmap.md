# 松匣功能完善与后续路线图

本文档用于安排松匣现有功能的优化和后续新增功能。优先级以个人日常使用为目标：先保证密码不会丢、不会误泄露、同步行为可理解，再增加自动填充和高级功能。

## 1. 当前能力基线

目前已经具备：

- 本地加密密码库，使用主密码创建、解锁和修改主密码。
- Android、iOS、macOS 和 Windows 的设备验证解锁接入。
- 密码条目的新增、查看、编辑、删除、收藏、搜索和批量操作。
- 标签、分组筛选，以及分组新建、重命名、删除和排序。
- 首页密码和网站显示开关，按名称或更新时间正序、倒序排列。
- 坚果云 WebDAV 配置、恢复、手动同步、自动同步、同步历史和三方冲突合并。
- KDBX 3/4 导入预览、重复检查、选择导入和独立密码导出。
- Android 和 macOS 的本地构建、安装及运行验证。

## 2. 推荐实施顺序

| 优先级 | 目标 | 建议 |
| --- | --- | --- |
| P0 | 安全、恢复和同步可靠性 | 下一阶段先完成 |
| P1 | 高频使用效率 | P0 稳定后实现 |
| P2 | 平台集成 | Android Autofill 优先 |
| P3 | 高级密码管理能力 | 按实际需求逐项增加 |

## 3. P0：现有功能必须优先优化

### 3.1 自动锁定

现状只有主动锁定和启动后的解锁流程，还应增加：

- 可设置无操作自动锁定时间：1、5、15、30 分钟或关闭。
- 应用进入后台超过指定时间后再锁定，避免下拉通知栏等短暂状态变化触发锁定。
- 桌面端根据键盘和鼠标无操作时间锁定。
- 锁定时释放密码库、`VaultKey` 和可控的敏感内存引用。

验收：后台短暂切换不锁定，超过用户设置的时间后必须重新验证。

### 3.2 剪贴板自动清理

- 复制密码后默认 30 秒自动清理，可提供 15、30、60 秒和关闭选项。
- 清理前检查剪贴板内容仍然是松匣写入的值，不能删除用户后来复制的新内容。
- 账号、网站、备注可以使用不同策略；默认只强制清理密码。
- Toast 显示“密码已复制，30 秒后清除”。

验收：密码按时清除，期间复制其他内容不会被误删。

### 3.3 隐私显示保护

- 应用进入后台时使用隐私遮罩，避免最近任务预览显示密码内容。
- Android 提供“禁止截屏”开关，开启后使用 `FLAG_SECURE`。
- 密码显示一段时间后自动恢复隐藏。
- 锁屏和设备验证过程中不得短暂显示已解密页面。

### 3.4 本地备份和恢复入口

底层已经保存上一份加密文件，但用户还缺少可操作的恢复界面：

- 检测当前密码库损坏时提示恢复 `vault.prev.pvlt`。
- 在设置中展示当前文件和备份文件的时间、大小及校验状态。
- 支持手动导出、导入松匣原生加密备份文件。
- 恢复前先创建当前状态的安全副本，避免二次误操作。

验收：模拟当前文件损坏后，可以从上一份加密备份恢复且条目完整。

### 3.5 WebDAV 同步可靠性

- 使用真实坚果云账号完成 Android 与 macOS 双设备回归测试。
- 覆盖新增、编辑、删除、分组重命名、分组删除、分组排序和主密码修改。
- 增加明确的冲突中心，让用户查看本机版本、远端版本并选择保留结果。
- 同步失败提示下一步操作，例如认证失败、网络失败、空间不足和远端文件损坏。
- 设置页展示上次成功同步时间、当前是否有本地未上传修改。
- 对 schema 3 的分组墓碑和排序时间补充专门的序列化、合并测试。

### 3.6 平台验证补齐

- Android 真机验证设备解锁绑定、重启、取消、失败和主密码回退。
- 带 Touch ID 的 macOS 验证 Secure Enclave 路径。
- iOS 真机验证构建、设备解锁和文件选择。
- Windows 验证 Windows Hello、DPAPI、构建和安装。
- Linux 在确定安全存储方案后再列为正式支持平台。

## 4. P1：高频体验优化

### 4.1 密码生成器

这是最值得优先增加的日常功能：

- 长度、大小写、数字、符号开关。
- 排除易混淆字符。
- 支持生成易读密码短语。
- 在新建和编辑条目时一键填入。
- 生成结果默认不写入历史或日志。

### 4.2 回收站

- 删除条目先进入本地加密回收站。
- 支持恢复和永久删除。
- 删除状态继续参与 WebDAV 同步。
- 可选 30 天后自动清理。

这样可以减少批量操作和多设备同步中的误删风险。

### 4.3 标签管理和高级筛选

- 首页增加标签筛选，但不在每张卡片上显示标签。
- 标签支持重命名、合并和删除。
- 搜索范围扩展到备注、标签和分组。
- 支持组合筛选：分组、标签、收藏。
- 提供“一键清除筛选”。

### 4.4 条目编辑体验

- 网站地址自动补充 `https://`，同时允许用户保留自定义协议。
- 保存前提示完全重复的条目，不强制阻止保存。
- 密码强度即时提示。
- 支持多个网站地址的增删和排序。
- 离开未保存的编辑页时弹出确认。
- 新建条目时记住最近使用的分组，但不永久改变默认分组。

### 4.5 桌面端操作效率

- 快捷键：新建、搜索、锁定、同步、复制账号和复制密码。
- 右键菜单和当前长按菜单保持一致。
- 列表与详情双栏布局，窄窗口继续使用底部查看面板。
- 支持方向键选择条目、Enter 查看、Esc 关闭面板。

### 4.6 设置页面整理

将更多菜单逐步整理为独立设置页：

- 安全：自动锁定、设备验证、剪贴板、截屏保护。
- 显示：首页显示密码、网站和排序方式。
- 同步：WebDAV、立即同步、同步状态和历史。
- 数据：KDBX、原生备份和恢复。

更多菜单只保留高频动作，避免选项继续变长。

## 5. P2：平台集成功能

### 5.1 Android Autofill Service

建议作为下一项大型功能，分三步交付：

1. 注册原生 Kotlin `AutofillService`，能在系统设置中启用并识别账号、密码字段。
2. 根据 App 包名和网页域名匹配松匣条目，支持选择账号并填充。
3. 接入设备验证和主密码回退，锁定状态不暴露明文数据。

同时测试 Chrome、Edge、Firefox、原生登录页和 WebView。部分 App 主动禁用 Autofill 时只能提示平台限制。

### 5.2 iOS Password AutoFill

- 实现 Credential Provider Extension。
- 与主应用共享加密密码库或受保护的最小索引。
- 使用系统认证解锁后选择并填充账号。
- 必须在真机和正式签名环境验证扩展权限。

### 5.3 浏览器扩展

- 第一阶段只支持本机通信、搜索和填充，不直接访问 WebDAV。
- 主应用保持唯一的解密与同步主体。
- 扩展和主应用之间使用认证过的本地通道。
- Chrome/Edge 优先，Firefox 后续评估。

### 5.4 桌面自动填充

桌面端缺少 Android/iOS 那样统一的系统框架，实现和维护成本较高。建议先完成浏览器扩展，再按实际需要评估 macOS 和 Windows 的原生辅助功能方案。

## 6. P3：高级功能

### 6.1 TOTP 动态验证码

- 支持手动输入密钥和扫描二维码。
- 查看面板展示当前验证码和倒计时。
- 一键复制验证码。
- 密钥继续作为密码库 payload 加密同步。

### 6.2 密码健康检查

- 弱密码、重复密码、长期未修改密码检查。
- 所有比较默认在本机完成。
- 如增加泄漏密码查询，仅发送不可逆的哈希前缀，并明确提供关闭开关。
- 不上传条目标题、用户名、网站或完整密码哈希。

### 6.3 条目历史版本

- 保存最近若干次修改的加密历史。
- 支持查看差异和恢复旧版本。
- 设置数量或时间上限，避免密码库无限增长。

### 6.4 更多条目类型

- 安全笔记。
- 银行卡。
- 身份信息。
- Wi-Fi 密码。
- 软件许可证。
- 自定义字段。

应先定义每种类型的真实使用场景，不为假设需求增加永久兼容层。

### 6.5 KDBX 增强

- 密钥文件。
- 自定义字段。
- 附件。
- 图标和更完整的分组层级映射。
- 导入报告和失败项导出。

### 6.6 加密附件

- 图片、证书和恢复码文件作为加密附件保存。
- 限制单文件和总容量。
- WebDAV 上传前仍保持端到端加密。
- 大文件需要独立同步和失败重试设计，不能直接塞进当前 JSON payload。

### 6.7 Passkey

Passkey 提供和保存涉及 Android Credential Manager、Apple Authentication Services 及网站协议适配，复杂度明显高于密码自动填充。建议在 Autofill 和浏览器扩展稳定后再评估。

## 7. 工程质量优化

### 7.1 自动化测试

- 为分组重命名、删除、排序和同步墓碑增加单元测试。
- 为自动锁定、剪贴板清理和设备验证增加生命周期测试。
- 为主要弹窗增加手机和桌面 Widget Test。
- 增加 Android 真机集成测试：创建、重启、解锁、同步和恢复。

### 7.2 持续集成

- GitHub Actions 执行格式检查、`flutter analyze` 和 `flutter test`。
- Android Release 构建只读取 GitHub Secrets，不提交 JKS 或密码。
- macOS 构建区分个人 ad-hoc 包和未来正式签名包。
- Release 自动生成校验值，方便验证下载文件完整性。

### 7.3 可访问性和国际化

- 检查大字体、屏幕阅读器、键盘焦点和颜色对比度。
- 图标按钮补齐语义标签和 Tooltip。
- 中文文案集中管理，再决定是否加入英文。
- 手机小屏和桌面窄窗口都不得出现布局溢出。

### 7.4 错误与日志

- 使用结构化错误码区分文件、加密、认证、网络和同步错误。
- 日志中禁止出现密码、密钥、Authorization、账号内容和完整 URL 查询参数。
- 提供“复制诊断信息”，只包含版本、平台、错误码和脱敏状态。

## 8. 当前不计划实现

根据当前产品范围，以下功能不进入路线图：

- 多个密码库。
- 多个 WebDAV 服务器。
- 在应用内删除坚果云远端密码库文件。
- Web 端直接解密密码库。
- 服务端账号系统和中心化明文搜索。

如果以后出现真实使用需求，再单独设计数据迁移和交互，不提前增加兼容层。

## 9. 建议的近期里程碑

### 里程碑 A：安全完善

- 自动锁定。
- 剪贴板自动清理。
- 后台隐私遮罩和 Android 截屏保护。
- 本地备份恢复入口。

### 里程碑 B：可靠同步

- 双设备坚果云完整回归。
- 分组同步专项测试。
- 冲突查看和处理界面。
- 同步状态说明和可操作错误提示。

### 里程碑 C：日常效率

- 密码生成器。
- 回收站。
- 标签管理和高级筛选。
- 桌面快捷键与右键菜单。

### 里程碑 D：Android 自动填充

- AutofillService 基础链路。
- 条目匹配与选择填充。
- 设备验证解锁和真机兼容测试。

推荐严格按 A → B → C → D 推进。自动填充价值很高，但它会扩大解锁和敏感数据暴露面，应建立在自动锁定、剪贴板清理、恢复能力和同步验证完成的基础上。
